# HoopCuts

HoopCuts turns full basketball games into highlight reels. The React and TypeScript review studio lets you choose clips, add sponsor logos, and export vertical reels. The Python analysis package can also run from the command line.

## Download and run

[Download the MIT-licensed source](https://github.com/EliasL15/hoopcuts/raw/refs/heads/main/hoopcuts-open-source.tar.gz), then extract it into a new directory.

```sh
mkdir hoopcuts-source
tar -xzf hoopcuts-open-source.tar.gz -C hoopcuts-source
cd hoopcuts-source
```

Open `README.md` inside the extracted source for project details and `hosted/README.md` for local setup and self-hosting instructions. The hosted HoopCuts service has been shut down.
